# 课程讲义目录

本目录只放**教学摘要层**，可提交。原书整理稿放 `reference_material/book_md/`，只在本机检索，不提交。

把《深度学习》选段整理成 6 份 Markdown，放在本目录。

## 命名

`DL-CH01-01.md`、`DL-CH02-01.md` ……  
`CH` 对应参考书章节，后面的序号是该章的第几份讲义。

## 每份文件头

```markdown
---
doc_id: DL-CH01-01
title: 深度学习简介
chapter: 1
kp_ids: [KP1-1, KP1-2]
source: 《深度学习》第 1 章（自制摘要）
source_pages: [1-8]
---
```

## 要求

- 用自己的话做摘要，不复制原书长段。
- 每份 800—1500 字，必须写 `source_pages`，能回到原文。
- 公式/定义保留原文页码；PDF 转 md 后抽查公式，必要时手动校对。
- 摘要不是事实源；和原文冲突时，以原文为准并修摘要。
- 先整理第 1 单元，够 D1 跑通；D2 前至少 4 份、最好 6 份。
